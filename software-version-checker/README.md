# software-version-checker

授業で使うソフトウェアのバージョンを一覧にして、教員の環境と比べるシェルスクリプト。

## 概要

| 項目 | 内容 |
| --- | --- |
| 時期 | 2020年3月〜10月 |
| 言語 | シェルスクリプト（bash） |

京都産業大学 情報理工学部の青木淳教授の授業では、教員が、自分の使っているソフトウェアのバージョンの一覧を、Web ページで公開していた。教員と同じバージョンを使っていれば、授業でのトラブルが減る。自分の PC に入っているソフトウェアのバージョンを、1つずつ調べて見比べる手間を省くために作った。

スクリプトは2つある。1つ目は、自分の PC のバージョンを一覧で表示する。2つ目は、教員の一覧を取得して、自分の PC のバージョンと並べて表示する。

リポジトリ全体の説明は、[リポジトリのトップの README](../README.md) を参照。

## ディレクトリ構成

| ファイル | 内容 |
| --- | --- |
| `aok_software_cheker.sh` | 授業で使うソフトウェアのバージョンを、分野ごとに一覧で表示する |
| `aok_software_cheker2.sh` | 教員が公開しているバージョンの一覧を取得して、自分の PC のバージョンと並べて表示する |

どちらも、オプションで、表示する分野を選ぶ。

| オプション | 表示する内容 |
| --- | --- |
| `--all` | すべて |
| `--macos` | macOS と Xcode |
| `--c` | C の開発に使うもの |
| `--ja` | Java の開発に使うもの |
| `--py` | Python の開発に使うもの |
| `--js` | JavaScript の開発に使うもの |
| `--rb` | Ruby の開発に使うもの |
| `--scm` | バージョン管理に使うもの |
| `--help` | オプションの説明 |

## 実行環境

当時使っていた環境のうち、実行に必要なソフトウェアを挙げる。当時は各ソフトウェアを常に最新版に更新していたので、バージョンは、リポジトリに記録が残っているものはその値を、残っていないものは当時の最新版を書いている。どちらでも分からないものは「不明」としている。

| ソフトウェア | バージョン | 用途 | 補足 |
| --- | --- | --- | --- |
| macOS | 10.15.7 Catalina | OS | 当時の README に記録。この環境での実行を想定して書いている |
| bash | 3.2.57 | スクリプトの実行 | macOS に付属するもの |
| curl | 7.64.1 | 教員の一覧の取得 | macOS に付属するもの。`aok_software_cheker2.sh` が使う |

バージョンを調べる対象のソフトウェア（Xcode、Java、Python、Node.js、Ruby、Git など）は、この表には入れていない。入っているものだけが、正しく表示される。

## セットアップ

用意するものはない。bash と curl は、macOS に最初から入っている。

## 実行方法

ファイル名を `bash` に渡して、表示したい分野のオプションを付けて実行する。

```sh
bash aok_software_cheker.sh --all
bash aok_software_cheker2.sh --all
```

オプションを付けずに実行すると、オプションの説明が表示される。

## 備考

- 調べる対象のソフトウェアが入っていない場合や、コマンドの場所が設定されていない場合は、エラーが表示される。
- `gcc` のバージョンを調べるときに、「Configured with: ...」という行もあわせて表示される。
- `aok_software_cheker2.sh` は、比べる相手のバージョンを、大学の Web ページから取得する。そのページが見られないときは、動かない。
- ファイル名の `cheker` は、`checker` のつづりの誤りだが、当時のままにしている。
