# setup-paper

卒業論文のひな形に、テーマや氏名を書き込んで、書き始められる状態にするシェルスクリプト。

## 概要

| 項目 | 内容 |
| --- | --- |
| 時期 | 2020年10月 |
| 言語 | シェルスクリプト（bash）、HTML、CSS |

卒業論文を、Word や LaTeX ではなく、HTML のファイルで書いていた。書き始めるときに、表紙や各ページに、テーマ、氏名、日付を1つずつ書き込む手間を省くために作った。

ひな形の HTML には、置き換えるための目印が書いてある。スクリプトは、質問に答えた内容と、実行した日の日付で、目印を置き換える。

| 目印 | 置き換える内容 |
| --- | --- |
| `theme` | 論文のテーマ |
| `gakubu`、`gakka` | 学部、学科 |
| `lastName`、`firstName` | 苗字、名前 |
| `fullName` | ローマ字の氏名 |
| `studentNumber` | 学生証番号の下6桁 |
| `YYYY`、`mm月dd日` | 実行した日の年、月日 |

リポジトリ全体の説明は、[リポジトリのトップの README](../README.md) を参照。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `setupPaper.sh` | 対話形式のスクリプト。質問に答えると、ひな形の中の目印を置き換える |
| `Makefile` | `make setup` で、`setupPaper.sh` を実行する |
| `paper_temp/` | 論文のひな形。表紙、要旨、目次、はじめに、本文（第1章〜第5章）、おわりに、参考文献、付録、索引の HTML と、スタイル（`assets/css/`） |

## 実行環境

| ソフトウェア | バージョン | 用途 |
| --- | --- | --- |
| macOS | 10.15 Catalina | OS。macOS の `sed` と `date` の動きを前提に書いている |
| GNU Make | 3.81 | コマンドの実行。macOS に付属 |

## 実行方法

このディレクトリで、次のコマンドを実行する。質問に順に答えると、最後に「実行してもいいですか？」と聞かれるので、`y` と答える。

```sh
make setup
```

`paper_temp/` の中の HTML が、入力した内容に書き換わる。元のひな形には戻せないので、やり直すときは、リポジトリから取り出し直す。

## 備考

- `paper_temp/` のスタイル（`assets/css/index.css`、`custom.css`）は、実際に書いた卒業論文のものと同じである。卒業論文は、このひな形から書き始めた。
- 目印は、単純な文字の置き換えで書き換える。入力した内容に `/` が含まれていると、置き換えに失敗する。
- 書き換えた HTML の書式を整える道具は、[`paper-format/`](../paper-format/) にある。
