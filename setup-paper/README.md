# setup-paper

卒業論文のひな形に、テーマや氏名を書き込んで、書き始められる状態にするシェルスクリプト。

## 概要

| 項目 | 内容 |
| --- | --- |
| 時期 | 2020年10月 |
| 言語 | シェルスクリプト（bash）、HTML、CSS |

卒業論文を、Word や LaTeX ではなく、HTML のファイルで書いていた。論文は、表紙、要旨、目次、各章などの、14個の HTML に分かれている。書き始めるときに、そのすべてに、テーマ、氏名、日付を1つずつ書き込む手間を省くために作った。

ひな形の HTML には、置き換えるための目印が書いてある。スクリプトを実行すると、テーマや氏名を順に質問される。答えると、ひな形の中の目印が、答えた内容と、実行した日の日付に置き換わる。

リポジトリ全体の説明は、[リポジトリのトップの README](../README.md) を参照。

## ディレクトリ構成

| ディレクトリ・ファイル | 内容 |
| --- | --- |
| `setupPaper.sh` | 対話形式のスクリプト。質問に答えると、ひな形の中の目印を置き換える |
| `Makefile` | `make setup` で、`setupPaper.sh` を実行する |
| `paper_temp/` | 論文のひな形 |
| `paper_temp/index.html` | 表紙 |
| `paper_temp/Summary/`、`Contents/`、`Introduction/` | 要旨、目次、はじめに |
| `paper_temp/Chapters/` | 本文。章の一覧と、第1章〜第5章（`Chapter1/`〜`Chapter5/`） |
| `paper_temp/Conclusion/`、`Bibliography/`、`Appendix/`、`Index/` | おわりに、参考文献、付録、索引 |
| `paper_temp/assets/css/` | スタイル（`index.css`、`custom.css`） |

スクリプトが置き換える目印は、次のとおりである。

| 目印 | 置き換える内容 |
| --- | --- |
| `theme` | 論文のテーマ |
| `gakubu`、`gakka` | 学部、学科 |
| `lastName`、`firstName` | 苗字、名前 |
| `fullName` | ローマ字の氏名 |
| `studentNumber` | 学生証番号の下6桁 |
| `YYYY`、`mm月dd日` | 実行した日の年、月日 |

## 実行環境

当時使っていた環境のうち、実行に必要なソフトウェアを挙げる。当時は各ソフトウェアを常に最新版に更新していたので、バージョンは、リポジトリに記録が残っているものはその値を、残っていないものは当時の最新版を書いている。どちらでも分からないものは「不明」としている。

| ソフトウェア | バージョン | 用途 | 補足 |
| --- | --- | --- | --- |
| macOS | 10.15.7 Catalina | OS | macOS に付属する `sed` と `date` の動きを前提に書いている |
| bash | 3.2.57 | スクリプトの実行 | macOS に付属するもの |
| GNU Make | 3.81 | コマンドの実行 | macOS に付属するもの |

## セットアップ

用意するものはない。bash、`sed`、`date`、Make は、macOS に最初から入っている。Linux では、`sed` のオプションの扱いが違うので、そのままでは動かない。

## 実行方法

このディレクトリで、次のコマンドを実行する。

```sh
make setup
```

次の順に質問されるので、答えていく。

1. 論文のテーマ
2. 学部の名前
3. 学科の名前
4. 苗字
5. 名前
6. ローマ字の氏名
7. 学生証番号の下6桁

最後に「実行してもいいですか？」と聞かれる。`y` と答えると、`paper_temp/` の中の HTML が、答えた内容に書き換わる。書き換えたあとの `paper_temp/` を、論文のフォルダとして使う。

## 備考

- 書き換えたあとは、元のひな形には戻せない。やり直すときは、リポジトリから取り出し直す。
- 目印は、単純な文字の置き換えで書き換える。答えた内容に `/` が含まれていると、置き換えに失敗する。
- `paper_temp/` のスタイル（`assets/css/index.css`、`custom.css`）は、実際に書いた卒業論文のものと同じである。卒業論文は、このひな形から書き始めた。
- 書いた HTML の書式を整える道具は、[`paper-format/`](../paper-format/) にある。
