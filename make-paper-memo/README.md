# make-paper-memo

論文を読むときのメモのファイルを、ひな形つきで作る AppleScript。

## 概要

| 項目 | 内容 |
| --- | --- |
| 時期 | 2020年4月 |
| 言語 | AppleScript |

論文を読んだときのメモを、毎回同じ形で書くために作った。実行すると、論文名を入力する画面が出る。入力すると、デスクトップに「`<論文名>_メモ`」というファイルができる。ファイルには、論文名、著者、発表年、作成日、管理番号の欄と、次の7つの見出しが、あらかじめ書き込まれている。

1. どんなもの
2. 先行研究との比較
3. 技術や手法のキモは
4. どうやって有効だと判断したか
5. 議論点
6. 次に読むべき論文
7. 用語

作成日には、実行した日時が入る。メモを Markdown で書くためのものと、テキストで書くためのものの、2つがある。

リポジトリ全体の説明は、[リポジトリのトップの README](../README.md) を参照。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `MakePaperMemoMd.scpt` | Markdown のファイル（`<論文名>_メモ.md`）を作る |
| `MakePaperMemoTxt.scpt` | テキストのファイル（`<論文名>_メモ.txt`）を作る |
| `MakePaperMemoMd.scpt.txt`、`MakePaperMemoTxt.scpt.txt` | 同じ名前の `.scpt` と、中身が同じファイル |

## 実行環境

| ソフトウェア | バージョン | 用途 |
| --- | --- | --- |
| macOS | 10.15 Catalina | OS。AppleScript と、ターミナル（Terminal.app）を使う |

## 実行方法

```sh
osascript MakePaperMemoMd.scpt
osascript MakePaperMemoTxt.scpt
```

スクリプトエディタ（Script Editor.app）で開いて、実行することもできる。当時は、アプリケーションの形に書き出して使っていた。

## 備考

- `.scpt` は、コンパイル済みの形式で、テキストエディタでは読めない。中身を読むには、スクリプトエディタで開くか、`osadecompile MakePaperMemoMd.scpt` を実行する。
- ファイルは、ターミナルを開いて、シェルのコマンドで作っている。論文名に、空白や、シェルで特別な意味を持つ文字（`/`、`&` など）が含まれていると、意図したファイルができない。
