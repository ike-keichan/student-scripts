# make-paper-memo

論文を読むときのメモのファイルを、ひな形つきで作る AppleScript。

## 概要

| 項目 | 内容 |
| --- | --- |
| 時期 | 2020年4月 |
| 言語 | AppleScript |

論文を読んだときのメモを、毎回同じ形で書くために作った。実行すると、論文名を入力する画面が出る。入力すると、デスクトップに「`<論文名>_メモ`」というファイルができる。ファイルには、論文名、著者、発表年、作成日、管理番号の欄と、次の7つの見出しが、あらかじめ書き込まれている。作成日には、実行した日時が入る。

1. どんなもの
2. 先行研究との比較
3. 技術や手法のキモは
4. どうやって有効だと判断したか
5. 議論点
6. 次に読むべき論文
7. 用語

メモを Markdown で書くためのものと、テキストで書くためのものの、2つがある。

リポジトリ全体の説明は、[リポジトリのトップの README](../README.md) を参照。

## ディレクトリ構成

| ファイル | 内容 |
| --- | --- |
| `MakePaperMemoMd.scpt` | Markdown のファイル（`<論文名>_メモ.md`）を作る。欄と見出しは、Markdown の見出しの書き方（`###`、`##`）で書き込まれる |
| `MakePaperMemoTxt.scpt` | テキストのファイル（`<論文名>_メモ.txt`）を作る。欄と見出しは、記号を付けずに書き込まれる |
| `MakePaperMemoMd.scpt.txt`、`MakePaperMemoTxt.scpt.txt` | 同じ名前の `.scpt` と、中身が同じファイル |

ファイルは、スクリプトエディタで保存したコンパイル済みの形式（`.scpt`）である。テキストエディタでは読めない。

## 実行環境

当時使っていた環境のうち、実行に必要なソフトウェアを挙げる。当時は各ソフトウェアを常に最新版に更新していたので、バージョンは、リポジトリに記録が残っているものはその値を、残っていないものは当時の最新版を書いている。どちらでも分からないものは「不明」としている。

| ソフトウェア | バージョン | 用途 | 補足 |
| --- | --- | --- | --- |
| macOS | 10.15 Catalina | OS | |
| AppleScript | 2.7 | スクリプトの実行 | macOS に付属するもの |
| スクリプトエディタ | 2.11 | スクリプトの編集と実行 | macOS に付属するもの |
| ターミナル | 2.10 | ファイルを作るコマンドの実行 | macOS に付属するもの。スクリプトが、ターミナルを開いてコマンドを実行する |

## セットアップ

用意するものはない。AppleScript、スクリプトエディタ、ターミナルは、macOS に最初から入っている。macOS 以外では実行できない。

## 実行方法

「スクリプトエディタ」でファイルを開き、実行ボタンを押す。論文名を入力する画面が出るので、入力して「OK」を押す。ターミナルが開き、デスクトップにファイルができる。

ターミナルから実行することもできる。

```sh
osascript MakePaperMemoMd.scpt
osascript MakePaperMemoTxt.scpt
```

中身をターミナルで読むときは、`osadecompile` を使う。

```sh
osadecompile MakePaperMemoMd.scpt
```

## 備考

- 当時は、スクリプトエディタでアプリケーションの形に書き出して使っていた。
- ファイルは、ターミナルで、シェルのコマンドを実行して作っている。論文名に、空白や、シェルで特別な意味を持つ文字（`/`、`&` など）が含まれていると、意図したファイルができない。
