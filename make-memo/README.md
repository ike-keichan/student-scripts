# make-memo

デスクトップに、今日の日付の名前のメモのファイルを作るシェルスクリプト。

## 概要

| 項目 | 内容 |
| --- | --- |
| 時期 | 2019年1月〜8月 |
| 言語 | シェルスクリプト（bash） |

メモを取るたびに、ファイルを作って、名前と日付を書く手間を省くために作った。実行すると、デスクトップに、今日の日付を名前にしたファイル（`20190113.txt` など）ができる。ファイルの中には、日付（`2019/01/13(日)` など）が、あらかじめ書き込まれている。

メモをテキストで書くためのものと、Markdown で書くためのものの、2つがある。どちらも、Automator（macOS に付属する、作業を自動にする道具）の「シェルスクリプトを実行」に書いて、アプリケーションの形にして使っていた。このディレクトリには、その中に書いていたコマンドを、シェルスクリプトとして入れている。

論文を読むときのメモを作る [`make-paper-memo/`](../make-paper-memo/) は、この道具を元に、あとから作ったものである。

リポジトリ全体の説明は、[リポジトリのトップの README](../README.md) を参照。

## ディレクトリ構成

| ファイル | 内容 |
| --- | --- |
| `MakeMemo.sh` | テキストのファイル（`<年月日>.txt`）を作り、1行目に日付を書き込む |
| `MakeMdFile.sh` | Markdown のファイル（`<年月日>.md`）を作り、タイトル、区切りの線、日付、サブタイトルの欄を書き込む |

`MakeMdFile.sh` が作るファイルの中身は、次のようになる。

```markdown
# タイトル
***

2019/08/31(土)

 ## サブタイトル
 +
```

## 実行環境

当時使っていた環境のうち、実行に必要なソフトウェアを挙げる。当時は各ソフトウェアを常に最新版に更新していたので、バージョンは、リポジトリに記録が残っているものはその値を、残っていないものは当時の最新版を書いている。どちらでも分からないものは「不明」としている。

| ソフトウェア | バージョン | 用途 | 補足 |
| --- | --- | --- | --- |
| macOS | 10.14 Mojave | OS | |
| bash | 3.2.57 | スクリプトの実行 | macOS に付属するもの |
| Automator | 2.9 | アプリケーションの形にする | macOS に付属するもの。スクリプトとして実行するだけなら、要らない |

## セットアップ

用意するものはない。bash と Automator は、macOS に最初から入っている。

## 実行方法

ホームディレクトリで、ファイル名を `bash` に渡して実行する。

```sh
cd ~
bash <このディレクトリの場所>/MakeMemo.sh
bash <このディレクトリの場所>/MakeMdFile.sh
```

デスクトップに、今日の日付の名前のファイルができる。

アプリケーションの形にするには、次の手順で行う。

1. Automator を開き、書類の種類で「アプリケーション」を選ぶ。
2. 「シェルスクリプトを実行」を追加する。シェルは `/bin/bash`、入力の引き渡し方法は「stdin へ」にする。
3. スクリプトの中身を、そのまま貼り付けて、保存する。

当時作ったアプリケーションは、このリポジトリの [Releases](https://github.com/ike-keichan/student-scripts/releases) に置いている。

## 備考

- `MakeMemo.sh` は、ファイルの場所を `Desktop/` と、いまいる場所からの相対で書いている。Automator から実行すると、ホームディレクトリで動くので、デスクトップにできる。ターミナルから実行するときは、先にホームディレクトリに移動する。`MakeMdFile.sh` は、`~/Desktop/` と書いているので、どこから実行しても、デスクトップにできる。
- 同じ日に2回実行すると、同じ名前のファイルを、上書きする。
- 日付の曜日は、パソコンの言語の設定に従う。日本語の設定では「日」、英語の設定では「Sun」のように表示される。
- スクリプトは、当時のアプリケーションの中に書いていたコマンドを、そのまま取り出したものである。
